# Задача 8. Как считать ROMI

ROMI = (выручка − затраты на рекламу) / затраты на рекламу. Формула
простая — сложность в том, какую выручку и какие затраты в неё
подставлять.

Код — [`src/romi.py`](../src/romi.py).

## Главный честный ответ: исторический ROMI посчитать нельзя

В `base.xlsx` нет ни одной цифры затрат на рекламу — знаменатель формулы
заполнить нечем.

## Что можно сделать вместо этого

**1. Завести реестр затрат на будущее.** Простая Google-таблица с
колонками: номер размещения, канал, дата, стоимость, креатив, ссылка на
пост, статус (`факт` / `оценка`) — см.
[`research/Реестр_рекламы_и_ресерч.xlsx`](../research/Реестр_рекламы_и_ресерч_P4.xlsx).
Инструмент специально примитивный — сложную таблицу никто не будет
заполнять вручную каждый раз.

**2. Для размещений, где реальной цены ещё нет, подставлять рыночный
ориентир — и явно помечать его как оценку.** Судя по открытым прайсам
(hot-head.ru, Neurounit, аукцион Telegram Ads), пост в канале на
~20 000 подписчиков стоит примерно **5 000–15 000 ₽**. Это диапазон, а
не число — используется только для демонстрации расчёта, а не выдаётся
за реальные затраты.

**3. Считать не одну метрику ROMI, а две, и показывать разрыв между
ними.**

| Метрика | На основе чего | Что показывает |
|---|---|---|
| `ROMI_attr` | модель атрибуции (задача 6) | кому мы приписали уже случившуюся продажу |
| `ROMI_inc` | результат holdout-теста (задача 7) | что реклама добавила на самом деле |

Разрыв между `ROMI_attr` и `ROMI_inc` — это и есть продажи, которые
случились бы даже без рекламы. Если считать только `ROMI_attr`,
органический спрос будет выглядеть как заслуга рекламы.

**4. Считать по марже, а не по выручке.** Параметр `margin` (доля от
цены, остающаяся после себестоимости курса) можно подставлять снаружи —
`margin=1.0` считает по чистой выручке, `margin=0.7` — по марже. Без
этого разные курсы с разной себестоимостью будут несправедливо
сравниваться по одной и той же шкале.

**5. Канал без затрат — это не бесконечный ROMI, а неопределённый.**
Свой канал и органика формально имеют затраты 0 ₽. Правильный ответ — явное "неопределено",
а не число.

**6. Рядом с ROMI считается CAC** (стоимость привлечения одного
покупателя по каналу) — метрика без деления на ноль, работает даже там,
где ROMI не считается.
